# Campos del frontmatter

Cada página comienza con un bloque de frontmatter. En las páginas de esta sección, se traducen `title` y `description`. Otros campos, como `order` y `slug`, se copian sin cambios a todos los idiomas.

| Campo         | Traducido |
| ------------- | ---------- |
| `title`       | Sí        |
| `description` | Sí        |
| `order`       | No         |
| `slug`        | No         |
