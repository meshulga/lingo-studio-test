# Aprobación de ejecuciones de traducción

Las ejecuciones de traducción consumen créditos, por lo que este repositorio solicita aprobación antes de que se inicie cada ejecución.

## Quién puede aprobar

Cualquier persona con acceso de escritura al repositorio puede aprobar o rechazar una ejecución.

## Qué cubre una aprobación

La propuesta enumera los archivos de origen y los idiomas a los que se traducirán. En una pull request, un nuevo push reemplaza una propuesta que sigue en espera.
