# Traducción de pull requests

Cuando un pull request modifica contenido en inglés, sus traducciones se pueden añadir a la misma rama antes de la revisión.

1. Abre un pull request desde una rama de este repositorio.
2. Espera el comentario que propone una traducción.
3. Responde con `/lingo approve` para iniciarla.

Los archivos traducidos se confirman en la rama del pull request, de modo que los revisores ven el cambio en el contenido original y sus traducciones juntos.
