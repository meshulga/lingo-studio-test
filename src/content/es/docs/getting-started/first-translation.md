# Tu primera traducción

Cada traducción comienza con un cambio en el contenido fuente en inglés.

## Haz un cambio

Edita cualquier archivo dentro de `src/content/en/`, por ejemplo un encabezado de esta página, y confírmalo en la rama predeterminada.

## Aprueba la ejecución

Este repositorio solicita aprobación antes de traducir cualquier contenido. Abre la comprobación **Lingo.dev Translations** en tu commit y elige **Approve** para continuar o **Deny** para omitirla.

## Revisa el resultado

Los archivos traducidos llegan en una pull request. Revisa los cambios y, a continuación, fusiona la pull request para publicarlos.
