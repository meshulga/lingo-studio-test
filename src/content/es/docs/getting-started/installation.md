# Instalación

Necesitas Node.js 20 o posterior y pnpm.

1. Clona el repositorio.
2. Instala las dependencias con `pnpm install`.
3. Inicia el servidor de desarrollo con `pnpm dev`.

Abre `http://localhost:3000` en tu navegador. El sitio te redirige al idioma que mejor se ajuste a la configuración de tu navegador.
