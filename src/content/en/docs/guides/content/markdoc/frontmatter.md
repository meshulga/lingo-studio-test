# Frontmatter fields

Each page starts with a frontmatter block. For pages in this section, `title` and `description` are translated. Other fields, such as `order` and `slug`, are copied to every language unchanged.

| Field         | Translated |
| ------------- | ---------- |
| `title`       | Yes        |
| `description` | Yes        |
| `order`       | No         |
| `slug`        | No         |
