# Approving translation runs

Translation runs use credits, so this repository asks for approval before each run starts.

## Who can approve

Anyone with write access to the repository can approve or deny a run.

## What an approval covers

The proposal lists the source files and the languages they will be translated into. On a pull request, a new push replaces a proposal that is still waiting.
