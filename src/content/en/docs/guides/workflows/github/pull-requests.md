# Translating pull requests

When a pull request changes English content, its translations can be added to the same branch before review.

1. Open a pull request from a branch in this repository.
2. Wait for the comment that proposes a translation.
3. Reply with `/lingo approve` to start it.

Translated files are committed to the pull request branch, so reviewers see the source change and its translations together.
