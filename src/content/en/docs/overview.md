# Documentation overview

This section is laid out like a product handbook. Pages sit at different folder depths, so tools that browse the repository can be tested against nested folders.

- **Getting started** covers installation and the first translation run.
- **Guides** explain how content is written and how translations reach the repository.
- **Reference** describes a sample API and the project's commands.

{% callout type="note" %}
Every page in this section is English source content. The Spanish, French and German versions come from the translation pipeline.
{% /callout %}
