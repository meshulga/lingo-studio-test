# Your first translation

Every translation starts with a change to English source content.

## Make a change

Edit any file under `src/content/en/`, for example a heading on this page, and commit it to the default branch.

## Approve the run

This repository asks for approval before anything is translated. Open the **Lingo.dev Translations** check on your commit and choose **Approve** to continue or **Deny** to skip.

## Review the result

Translated files arrive in a pull request. Review the changes, then merge the pull request to publish them.
