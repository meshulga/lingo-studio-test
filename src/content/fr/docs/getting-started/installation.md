# Installation

Vous avez besoin de Node.js 20 ou version ultérieure, ainsi que de pnpm.

1. Clonez le dépôt.
2. Installez les dépendances avec `pnpm install`.
3. Démarrez le serveur de développement avec `pnpm dev`.

Ouvrez `http://localhost:3000` dans votre navigateur. Le site vous redirige vers la langue qui correspond le mieux aux paramètres de votre navigateur.
