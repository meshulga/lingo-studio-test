# Votre première traduction

Chaque traduction commence par une modification du contenu source en anglais.

## Effectuer une modification

Modifiez n'importe quel fichier sous `src/content/en/`, par exemple un titre de cette page, puis validez-le sur la branche par défaut.

## Approuver l'exécution

Ce dépôt demande une approbation avant que quoi que ce soit ne soit traduit. Ouvrez la vérification **Lingo.dev Translations** sur votre commit et choisissez **Approve** pour continuer ou **Deny** pour ignorer.

## Examiner le résultat

Les fichiers traduits arrivent dans une pull request. Examinez les modifications, puis fusionnez la pull request pour les publier.
