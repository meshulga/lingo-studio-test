# pnpm dev

Démarre le serveur de développement Next.js sur le port 3000.

```bash
pnpm dev
```

Les pages se rechargent lorsque vous enregistrez un fichier source, ce qui vous permet de vérifier une modification sans redémarrer le serveur.
