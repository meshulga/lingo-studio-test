# Traduire les pull requests

Lorsqu'une pull request modifie du contenu en anglais, ses traductions peuvent être ajoutées à la même branche avant la relecture.

1. Ouvrez une pull request à partir d'une branche de ce dépôt.
2. Attendez le commentaire qui propose une traduction.
3. Répondez avec `/lingo approve` pour la lancer.

Les fichiers traduits sont commités dans la branche de la pull request, afin que les relecteurs voient la modification source et ses traductions ensemble.
