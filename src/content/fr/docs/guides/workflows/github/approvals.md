# Approbation des exécutions de traduction

Les exécutions de traduction consomment des crédits ; ce dépôt demande donc une approbation avant le lancement de chaque exécution.

## Qui peut approuver

Toute personne disposant d'un accès en écriture au dépôt peut approuver ou refuser une exécution.

## Ce que couvre une approbation

La proposition répertorie les fichiers sources et les langues dans lesquelles ils seront traduits. Dans une pull request, un nouveau push remplace une proposition encore en attente.
