# Champs du frontmatter

Chaque page commence par un bloc de frontmatter. Pour les pages de cette section, `title` et `description` sont traduits. Les autres champs, tels que `order` et `slug`, sont copiés tels quels dans chaque langue.

| Champ         | Traduit |
| ------------- | ---------- |
| `title`       | Oui        |
| `description` | Oui        |
| `order`       | Non         |
| `slug`        | Non         |
