# Dokumentationsübersicht

Dieser Bereich ist wie ein Produkthandbuch aufgebaut. Die Seiten liegen in unterschiedlichen Ordnertiefen, sodass Tools, die das Repository durchsuchen, anhand verschachtelter Ordner getestet werden können.

- **Erste Schritte** behandelt die Installation und den ersten Übersetzungslauf.
- **Leitfäden** erklären, wie Inhalte verfasst werden und wie Übersetzungen ins Repository gelangen.
- **Referenz** beschreibt eine Beispiel-API und die Befehle des Projekts.

{% callout type="note" %}
Jede Seite in diesem Bereich ist englischer Quellinhalt. Die spanischen, französischen und deutschen Versionen stammen aus der Übersetzungspipeline.
{% /callout %}
