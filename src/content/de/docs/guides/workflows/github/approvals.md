# Übersetzungsläufe freigeben

Übersetzungsläufe verbrauchen Credits, daher verlangt dieses Repository vor jedem Start eines Laufs eine Freigabe.

## Wer freigeben kann

Jede Person mit Schreibzugriff auf das Repository kann einen Lauf freigeben oder ablehnen.

## Was eine Freigabe umfasst

Der Vorschlag listet die Quelldateien und die Sprachen auf, in die sie übersetzt werden. Bei einem Pull Request ersetzt ein neuer Push einen Vorschlag, der noch auf Freigabe wartet.
