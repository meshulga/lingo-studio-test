# Pull Requests übersetzen

Wenn ein Pull Request englische Inhalte ändert, können die zugehörigen Übersetzungen vor der Überprüfung demselben Branch hinzugefügt werden.

1. Öffne einen Pull Request aus einem Branch in diesem Repository.
2. Warte auf den Kommentar, der eine Übersetzung vorschlägt.
3. Antworte mit `/lingo approve`, um sie zu starten.

Übersetzte Dateien werden in den Branch des Pull Requests committet, sodass Reviewer die Änderung am Original und die zugehörigen Übersetzungen gemeinsam sehen.
