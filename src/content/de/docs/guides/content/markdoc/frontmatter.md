# Frontmatter-Felder

Jede Seite beginnt mit einem Frontmatter-Block. Bei Seiten in diesem Bereich werden `title` und `description` übersetzt. Andere Felder wie `order` und `slug` werden unverändert in jede Sprache kopiert.

| Feld         | Übersetzt |
| ------------- | ---------- |
| `title`       | Ja        |
| `description` | Ja        |
| `order`       | Nein         |
| `slug`        | Nein         |
