# pnpm dev

Startet den Next.js-Entwicklungsserver auf Port 3000.

```bash
pnpm dev
```

Seiten werden neu geladen, wenn du eine Quelldatei speicherst. So kannst du eine Änderung prüfen, ohne den Server neu zu starten.
