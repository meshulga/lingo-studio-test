# Installation

Du benötigst Node.js 20 oder höher und pnpm.

1. Klone das Repository.
2. Installiere die Abhängigkeiten mit `pnpm install`.
3. Starte den Entwicklungsserver mit `pnpm dev`.

Öffne `http://localhost:3000` in deinem Browser. Die Website leitet dich automatisch zu der Sprache weiter, die am besten zu deinen Browsereinstellungen passt.
