# Deine erste Übersetzung

Jede Übersetzung beginnt mit einer Änderung am englischen Quellinhalt.

## Eine Änderung vornehmen

Bearbeite eine beliebige Datei unter `src/content/en/`, zum Beispiel eine Überschrift auf dieser Seite, und committe sie auf den Standard-Branch.

## Den Lauf genehmigen

Dieses Repository verlangt eine Genehmigung, bevor etwas übersetzt wird. Öffne den Check **Lingo.dev Translations** an deinem Commit und wähle **Approve**, um fortzufahren, oder **Deny**, um zu überspringen.

## Das Ergebnis prüfen

Übersetzte Dateien kommen in einem Pull Request an. Prüfe die Änderungen und merge den Pull Request anschließend, um sie zu veröffentlichen.
